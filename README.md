# University Events · 2024

A platform for discovering and managing university events, including event browsing, registration, and administration.  
Developed in 3 days during a hackathon, where our team took __1st place__. After the competition, the project was further improved and refined.

[**Live Demo →**](https://bsuir.online/)

## Features
- Browse and filter university events
- Individual and team registration for events
- Admin panel for managing events and participants
- Email newsletter subscription
- Form validation
- Responsive design for desktop and mobile
- Database architecture designed for future growth

## Getting Started
Create `.env` files based on `.env.example`.

```bash
cd frontend && npm install && npm start   # http://localhost:3001
cd backend && ./gradlew start             # http://localhost:5001
```
